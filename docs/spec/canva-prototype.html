06 / HINTERGRUND

     
Info & Arbeitsweise

     

      
Repository zuerst verstehen.

      
Repository, Rekonstruktion, Run ist eine clientseitige Arbeitsoberfläche für die strukturierte Übergabe von Projektinformationen. Sie erzeugt keine externe GitHub-Abfrage: GitHub-Links dienen als nachvollziehbare Referenz, während lokale Ordner direkt im Browser analysiert werden.

      

       
Datenschutz & Verlauf

       
Der Inhalt lokaler Dateien verbleibt im aktuellen Browserfenster. Nur die Nutzungshistorie – Zeitpunkt, Aktion, Modell und Status – wird in deiner Canva Sheet gespeichert. Du kannst die gespeicherten Vorgänge über die Data-Schaltfläche in Canva einsehen.
